# Exercícios Beecrowd: Condicionais sem Laços

## Objetivo
Esta lista reúne exercícios da categoria **Iniciante** do Beecrowd que podem ser trabalhados com estruturas condicionais, sem exigir o uso de laços de repetição como `for` e `while`.

O foco é praticar:
- `if`
- `if...else`
- `if...else if...else`
- `switch-case`
- condicionais aninhadas

## 1. Exercícios indicados para decisão simples
- `1035` Teste de Seleção 1
- `1036` Fórmula de Bhaskara
- `1037` Intervalo
- `1046` Tempo de Jogo
- `1048` Aumento de Salário
- `1050` DDD
- `1052` Mês
- `1933` Tri-du
- `2160` Nome no Formulário
- `2344` Notas da Prova

## 2. Exercícios indicados para múltiplos casos

- `1047` Tempo de Jogo com Minutos
- `1051` Impostos
- `1847` Bem-vindos e Bem-vindas ao Inverno!
- `2057` Fuso Horário
- `2670` Máquina de Café
- `2702` Escolha Difícil

## 3. Exercícios indicados para condicionais aninhadas

- `2059` Ímpar, Par ou Roubo
- `2235` Andando no Tempo

## 4. Melhores exercícios para uma aula sobre condicionais aninhadas
Se a proposta da aula for trabalhar especificamente estruturas condicionais aninhadas, os exercícios mais adequados desta lista são:

1. `1049` Animal
2. `1040` Média 3
3. `1045` Tipos de Triângulos
4. `2313` Qual Triângulo
5. `2059` Ímpar, Par ou Roubo
